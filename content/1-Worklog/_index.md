**On this page**, you will need to introduce your worklog. **How** did you complete it? How many weeks did you take to complete the program? **What** did you do in those weeks?

Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period) with weekly contents as follows:

**Week 1:** [Getting familiar with AWS and EC2 basics](1.1-week1/)

**Week 2:** [Learning AWS Storage Services (S3, EBS, EFS, CloudFront)](1.2-week2/)

**Week 3:** [IAM & Security — Identity, Policies, Roles, Best Practices](1.3-week3/)

**Week 4:** [AWS Networking — VPC, Subnets, Routing, Security Groups](1.4-week4/)

**Week 5:** [Databases on AWS — RDS, Snapshots, Multi-AZ, Spring Boot Integration](1.5-week5/)

**Week 6:** [Deploying Applications with AWS Elastic Beanstalk](1.6-week6/)

**Week 7:** [Docker & AWS ECS — Containers, ECR, Fargate Deployment](1.7-week7/)

**Week 8:** [Serverless — AWS Lambda, S3 Event Triggers, DynamoDB, API Gateway](1.8-week8/)

**Week 9:** [AWS Monitoring — CloudWatch, CloudTrail, X-Ray](1.9-week9/)

**Week 10:** [CI/CD with AWS Developer Tools — CodeCommit, CodeBuild, CodeDeploy, CodePipeline](1.10-week10/)

**Week 11:** [Advanced AWS Architecture — AutoScaling, Load Balancer, Route53, Networking](1.11-week11/)

**Week 12:** [Final Project — Deploying a Complete Spring Boot System on AWS](1.12-week12/)
