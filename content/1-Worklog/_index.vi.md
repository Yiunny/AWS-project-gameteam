**Trong trang này**, bạn sẽ giới thiệu worklog của bạn — **bạn đã hoàn thành như thế nào**, bạn học trong **bao nhiêu tuần**, và **mỗi tuần bạn đã làm gì**.

Thông thường và theo tiêu chuẩn, một worklog kéo dài khoảng 3 tháng thực tập, với nội dung các tuần như sau:

**Tuần 1:** [Làm quen AWS và EC2 cơ bản](1.1-week1/)

**Tuần 2:** [Tìm hiểu dịch vụ lưu trữ AWS (S3, EBS, EFS, CloudFront)](1.2-week2/)

**Tuần 3:** [IAM & Bảo mật — Users, Policies, Roles, Best practices](1.3-week3/)

**Tuần 4:** [Mạng AWS — VPC, Subnet, Routing, Security Groups](1.4-week4/)

**Tuần 5:** [Cơ sở dữ liệu trên AWS — RDS, Snapshot, Multi-AZ, tích hợp Spring Boot](1.5-week5/)

**Tuần 6:** [Triển khai ứng dụng với AWS Elastic Beanstalk](1.6-week6/)

**Tuần 7:** [Docker & AWS ECS — Containers, ECR, Fargate](1.7-week7/)

**Tuần 8:** [Serverless — AWS Lambda, S3 Trigger, DynamoDB, API Gateway](1.8-week8/)

**Tuần 9:** [Giám sát hệ thống — CloudWatch, CloudTrail, X-Ray](1.9-week9/)

**Tuần 10:** [CI/CD với AWS Developer Tools — CodeCommit, CodeBuild, CodeDeploy, CodePipeline](1.10-week10/)

**Tuần 11:** [Chủ đề nâng cao — AutoScaling, Load Balancer, Route53, Networking](1.11-week11/)

**Tuần 12:** [Dự án cuối kỳ — Triển khai hệ thống Spring Boot hoàn chỉnh trên AWS](1.12-week12/)
