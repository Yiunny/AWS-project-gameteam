## Những điểm nổi bật

### AWS CodeCommit
- Dịch vụ kho Git bảo mật, có khả năng mở rộng trên AWS  
- Hỗ trợ các workflow GitFlow, Trunk-Based, và feature-branch  
- Phù hợp cho hợp tác, quản lý phiên bản và tự động hóa workflow  

### AWS CodeBuild
- Dịch vụ build hoàn toàn quản lý để biên dịch, kiểm thử và đóng gói code  
- Hỗ trợ cấu hình buildspec tùy chỉnh và build song song  
- Tích hợp pipeline kiểm thử tự động cho CI/CD  

### AWS CodeDeploy
- Tự động triển khai ứng dụng trên EC2, Lambda và on-premises  
- Hỗ trợ các chiến lược triển khai Blue/Green, Rolling và Canary  
- Giảm downtime và rủi ro triển khai nhờ kiểm soát traffic-shifting  

### AWS CodePipeline
- Orchestration CI/CD end-to-end tích hợp các công cụ DevOps trên AWS  
- Tự động hóa các giai đoạn build, test và deploy với tracking phiên bản đầy đủ  
- Phù hợp cho continuous delivery, pipelines đa môi trường và tự động hóa workflow  

### AWS CloudFormation
- Template khai báo để provision và quản lý tài nguyên AWS  
- Quản lý stack với drift detection và rollback  
- Đảm bảo tự động hóa hạ tầng nhất quán và có thể tái lập  

### AWS CDK (Cloud Development Kit)
- Infrastructure as Code sử dụng ngôn ngữ lập trình quen thuộc  
- Cung cấp các construct cao cấp và pattern tái sử dụng cho phát triển nhanh  
- Tích hợp liền mạch với CloudFormation để triển khai  

### Dịch vụ Container trên AWS
- Kiến thức cơ bản về Docker cho microservices và containerization  
- Amazon ECR cho lưu trữ image, quét và lifecycle policies  
- Amazon ECS & EKS triển khai container có khả năng mở rộng và orchestration  
- AWS App Runner để hosting ứng dụng container đơn giản  

### Giám sát & Observability
- Amazon CloudWatch: metrics, logs, alarms và dashboards  
- AWS X-Ray: tracing phân tán và phân tích hiệu năng  
- Cung cấp khả năng giám sát full-stack và visibility hoạt động  

### Best Practices DevOps & Case Studies
- Chiến lược triển khai: feature flags, A/B testing, và canary releases  
- Tích hợp kiểm thử tự động trong pipeline CI/CD  
- Workflow quản lý incident và postmortem hiệu quả  
- Case studies: chuyển đổi DevOps tại startup và doanh nghiệp
